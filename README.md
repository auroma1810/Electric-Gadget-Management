\# Electric Gadget Management System



A comprehensive hybrid management solution built using ASP.NET Core MVC for web access and C# WinForms for a robust desktop experience.



\## Features

\- Role-Based Access Control

\- Hybrid Web \& Desktop Integration

\- Product Management

\- Customer Management

\- Cart \& Orders

\- Multi-Branch Support

\- Data Backup \& Recovery



\## Technologies

\- C# .NET

\- ASP.NET Core MVC

\- Windows Forms (WinForms)

\- SQL Server

\- Entity Framework Core



\## Installation

1\. Clone the repository

2\. Restore dependencies: `dotnet restore`

3\. Apply migrations: `dotnet ef database update`

4\. Run: `dotnet run`
